# Connect to ChatGPT

MCP URL after deployment: `http://127.0.0.1:8788/mcp`

1. Open ChatGPT developer mode.
2. Create an app and enter the public MCP URL.
3. Choose OAuth and scan tools.
4. Complete consent with the deployed ADMIN_USERNAME and ADMIN_PASSWORD.
5. Test read-only tools first, then approval-bound tools.
