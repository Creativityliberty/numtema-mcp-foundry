# Sprint 0.9 — Durable Dispatch Authorization Ledger Design

## Goal

Consume an `AuthorizedExecutionEnvelope` exactly once, reserve its execution nonce, idempotency key and budget atomically, persist the authorization transition durably, and issue signed dispatch receipts without performing provider network I/O.

## Architecture

The ledger directory contains immutable metadata and an append-only `events.jsonl` journal. The journal is the source of truth; snapshots are reconstructed and verified from its ordered SHA-256 hash chain. Mutations acquire an atomic directory lock, validate the complete journal, append one fsynced event, release the lock, then return a signed receipt.

## State machine

```text
authorized → reserved → dispatched
                    ↘ released(cancelled|expired)
```

A nonce remains consumed after release because the approval and authorization are single-use. Released reservations free budget but never permit replay. An exact retry with the same idempotency key and envelope digest returns the existing reservation without appending a second event. Reusing the key with different input is rejected.

## Security invariants

- Only `dispatch_permitted=true` envelopes with valid SHA-256 integrity may be reserved.
- Expired envelopes are rejected.
- Required idempotency keys must be present.
- Execution nonces are permanently single-use.
- Active reserved and dispatched amounts count against the signed budget snapshot.
- The ledger rejects broken sequence, previous-digest or event-integrity chains.
- Receipts are Ed25519-signed by a key whose trust-store purpose is `dispatch`.
- No secret, credential value or provider network response is persisted.
- Sprint 0.9 performs no provider request.

## CLI

```text
foundry ledger init DIR
foundry ledger status --ledger DIR
foundry dispatch reserve --ledger DIR --envelope FILE --signing-key FILE --key-id ID
foundry dispatch commit --ledger DIR --reservation ID --signing-key FILE --key-id ID
foundry dispatch release --ledger DIR --reservation ID --reason cancelled|expired --signing-key FILE --key-id ID
foundry dispatch verify --receipt FILE --trust-store FILE
```
