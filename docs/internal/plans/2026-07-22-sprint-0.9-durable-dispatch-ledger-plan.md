# Durable Dispatch Authorization Ledger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Build a zero-runtime-dependency, file-backed, append-only authorization ledger with atomic replay, idempotency and budget reservations plus signed receipts.

**Architecture:** Add a focused `src/dispatch/` subsystem. Use `mkdir` as the cross-process lock primitive and `events.jsonl` as the durable source of truth. Reconstruct state for every operation and verify the full hash chain before mutation.

**Tech Stack:** Node.js 22, TypeScript strict, `node:fs/promises`, Ed25519, SHA-256, `node:test`.

## Global Constraints

- Zero runtime dependencies.
- No provider network execution.
- No private key or secret in distributed examples, logs, snapshots or receipts.
- Exact retries are idempotent; conflicting retries fail closed.
- Every JSON source remains mirrored under `bundle/json/`.

- [ ] Add dispatch types and durable file store.
